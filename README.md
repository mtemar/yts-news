# YTS News

A public, static news website for Vanuatu, hosted on GitHub Pages.

## Publishing

Edit `articles.json` to add articles. Each article needs a unique `id`, `title`, `category`, `date` (YYYY-MM-DD), `author`, `summary`, and `body` (array of paragraphs). Articles are displayed newest first.

## GitHub Pages

Open Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

Expected URL: https://mtemar.github.io/yts-news/

## Editorial standards

Verify claims, attribute sources, seek a right of reply for serious allegations, and publish corrections when necessary. Do not publish private information without a legitimate public-interest justification.

This initial site contains one welcome article, not a fabricated news story.
